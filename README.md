# ИИ в Граданализе / СПбГАСУ

31-слайдовая статическая веб-презентация. Автор и докладчик: Никита Скорняков, [@skornyakov_nik](https://t.me/skornyakov_nik).

## Открыть

Откройте `index.html` в современном Chrome, Edge, Firefox или Safari. Интернет для показа не нужен: все изображения, стили и код находятся в проекте. Сборка, установка пакетов, API-ключи и серверная часть не требуются. Полноэкранный режим зависит от разрешений браузера; можно использовать F11.

Для локального HTTP-просмотра из этой папки: `python -m http.server 8000 --bind 127.0.0.1`, затем откройте `http://127.0.0.1:8000`.

## Управление

- `←` / `→`, `PageUp` / `PageDown`, `Space` / `Shift+Space` — смена слайда. Колесо и горизонтальный свайп также работают.
- `Home` / `End` — первый / последний слайд; `M` или счётчик — оглавление; `F` — полный экран.
- Нажатие на скриншот открывает его целиком в увеличенном виде. `Esc` закрывает изображение или оглавление.
- Слайды 18 и 24: кнопки кадров и переключатель «Авто». Автосмена каждые 2,4 секунды; переход на другой слайд останавливает её.
- Слайды 10, 16, 20, 26: кнопки выделяют части интерфейса, «Весь экран» убирает выделение.
- Кнопка `◌` отключает движение. Системная настройка `prefers-reduced-motion` автоматически отключает анимации и параллакс. Медленная отрисовка включает статичный фон автоматически.
- Прямые ссылки: `#slide-01` … `#slide-31`. История браузера поддерживается.

Композиция имеет пропорции 16:9. На экранах других пропорций остаются поля, чтобы не обрезать содержание. Для телефона удобен горизонтальный режим. При фокусе на кнопке пробел нажимает её, как принято в доступных интерфейсах; стрелки продолжают листать слайды.

## GitHub Pages

1. Создайте репозиторий GitHub. Публичный репозиторий подходит для бесплатной публикации Pages; доступность Pages для приватного зависит от тарифа и настроек организации.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `styles.css`, `script.js`, `assets/`, `README.md`, `.nojekyll`. Не загружайте весь ZIP одним файлом.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Укажите **main**, папку **/ (root)** и сохраните.
6. Дождитесь завершения публикации. Откройте выданный GitHub адрес и проверьте его на другом устройстве, например с `#slide-18` в конце.

Публичная публикация делает скриншоты доступными посетителям сайта. Репозиторий: https://github.com/skornyakov17/ai-gradanaliz. Адрес презентации после развёртывания: https://skornyakov17.github.io/ai-gradanaliz/.

## Редактирование

`script.js`: массив `slideData` задаёт 31 экран, привязку изображений, подписи, главы и типы композиций. `styles.css`: цвета, типографика, отступы и анимации. `index.html`: постоянная рамка и элементы управления. Путь ко всем файлам относительный, поэтому проект работает в подпапке GitHub Pages.

## Исходные материалы

Тексты и факты взяты из предоставленного `AI_Gradanalis_Codex_TZ.pdf`; это материалы докладчика, а не независимая проверка результатов кейсов. 20 изображений извлечены из встроенных растров PDF без генеративной подмены, ретуши или кадрирования. PNG сохраняет доступное разрешение исходника PDF; отдельные полноразмерные оригиналы пользователем не предоставлены. Масштабирование не добавляет исходным скриншотам детализации. Видеофайлы не имитируются: слайды 14, 24 и 25 показывают предоставленные кадры.

Визуальный ориентир: https://nakarandashe27.github.io/LectoriySPbGASU/#slide-01. Брендинг, графика и код референса не копировались; использованы общие приёмы крупной типографики, постоянной рамки и мягких переходов. Фоновая городская геометрия абстрактна и не представляет реальные GIS-данные.
